# Project topic: Indium

## Short description

Indium is a mobile app like letterboxd but with less features. So it is for user to keep track of the movies they watch. Users can search for movies, rate and review them, keep a watchlist, watch trailers and follow friends to see what they’ve rated.

## Technologies

• React Native with Expo
• Firebase Authentication (login and register)
• Firebase Firestore (ratings, reviews, watchlist, friends)
• TMDB REST API (movie search, details, posters, cast, trailers)
• Expo APIs: expo-image-picker, expo-haptics, expo-brightness, expo-speech

## Main features

• Register and log in with Firebase Authentication
• Search movies through the TMDB API
• Movie detail page (poster, synopsis, cast, release date, trailer)
• Watch the movie trailer directly in the app (fetched via TMDB's video endpoint, hosted on YouTube)
• Cinema mode toggle that dims the screen brightness while watching a trailer (expo-brightness)
• Listen to the movie synopsis read aloud (expo-speech)
• Rate movies out of 5, with half stars (0.5 stars), with haptic feedback on tap (expo-haptics)
• Write a short review for each movie
• Watchlist: add and remove movies to watch later
• Friends: search users, add friends, and see their recent ratings and reviews
• Profile page with a profile picture (expo-image-picker) and a list of your rated movies
